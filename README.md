# CaixaFuturo

Projeto open source **em fase de planejamento**, para projetar o caixa de pequenos comércios/restaurantes e simular decisões com cálculos verificáveis, sem IA externa no runtime.

**Status em 11/11/2026:** planejamento, **nenhuma funcionalidade implementada**, nenhuma demo do aplicativo, teste de produto ou medição de cobertura. Sprint 1 depende de autorização explícita.
