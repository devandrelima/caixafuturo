## 5. Limitações e pendências (não omitidas)
1. **Alcance externo não verificado:** os testes pelo IP público partiram da própria VPS. Se o navegador do usuário não conectar, a causa provável é firewall do provedor (ver `s01-docker.md`).
2. **Sem ferramenta automática de acessibilidade (axe/Lighthouse):** contraste foi validado pelos tokens (`tools/validar_design.py`, ≥ 4,5:1 nos pares principais), não medido na página renderizada; verificações a11y do E2E são programáticas e parciais.
3. **Só Chromium** foi testado; Firefox e Safari/iOS não foram.
4. **Zoom extremo no celular:** a 390px com 200% de zoom (195 CSS px, abaixo do piso de 320px do WCAG 1.4.10) o menu e *Movimentações* ainda geram rolagem horizontal da página; de 260px para cima não há. Ver [`s01-visual.md`](s01-visual.md). Correção exige editar código de produção (fora do escopo da T03; replanejamento).
5. **IndexedDB não é backup** e não sincroniza entre dispositivos; HTTP público não deve ser usado com dados reais.
6. Sem aprovação humana: a Sprint 1 **não** está aprovada; a S02 não foi iniciada.
