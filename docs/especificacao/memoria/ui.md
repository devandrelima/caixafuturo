# Memória seletiva — interface

**Direção adotada do usuário:** CaixaFuturo clean/minimalista, warm off-white, grafite e destaque amarelo-dourado, levemente cartoonesco **com elementos 2D originais discretos**, não infantil; não copiar marcas/mascotes das capturas. Fonte de verdade: docs/especificacao/design/README.md + tokens.json + componentes.md + telas/S01.md (S01) ou evolucao.md (S02–S06), além de qualidade.md. **Não duplicar tokens nesta memória.**

Domínio UI: componentes funcionais src/components e src/app; testes em src/components/__tests__ e tests/e2e; acessibilidade, responsividade e estados carregando/erro/vazio/riscos são parte da entrega. UI consome serviços financeiros, não recalcula dinheiro independentemente. Inventariar skills visuais **efetivamente instaladas** no executor e justificar escolha/fallback. Evidência de screenshots não pode ser inventada. Nenhuma tela nova de sprint futura antes do seu escopo.
